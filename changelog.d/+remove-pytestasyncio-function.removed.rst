The internal ``PytestAsyncioFunction`` item class and its subclasses have been removed. pytest-asyncio no longer collects async tests as a dedicated item type; it classifies items at run time from their marker and callable. Importing ``pytest_asyncio.plugin.PytestAsyncioFunction`` now raises ``ImportError``. Code that imported it or used ``isinstance`` checks against it should use :func:`pytest_asyncio.is_async_test` instead.
