Each async fixture and each test runs in an asyncio task of its own, and the setup and teardown of an async generator fixture share a task; context variables behave as before.
When a task of pytest-asyncio's is cancelled, for example by a task group spanning a fixture's ``yield`` whose child failed, the running test or fixture setup is cancelled and the event loop accepts no new tests or fixture setups; fixture teardowns still run.
A cancelled fixture setup or teardown is reported as ``PytestAsyncioError``; a refused test or fixture setup, as ``RuntimeError``.
A test's failure is delivered to pytest rather than ending the test's task with it.
pytest-asyncio manages internal tasks that may appear in ``asyncio.all_tasks()``; their names, number and arrangement are not part of its public API.
See :ref:`concepts/tasks`.
